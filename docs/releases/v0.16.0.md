# KCF Tools v0.16.0

KCF Tools v0.16.0 extends the Qt6 GUI with Local and Remote
Topic plotting, bounded numeric history, and CSV export.

This release is built against KCF Core v5.6.2.

## Changes

- Local Topic numeric field Plot and CSV export
- Remote Topic subscription, Plot, and CSV integration
- Remote Workspace UI and session-aware observation improvements
- Real KCF Backend as the default for packaged builds
- Executable renamed to kcf_tools
- Four-platform native Debian packaging and CI/CD

## Running

After installing the package:

    kcf_tools

The packaged application selects the real KCF Backend by default.

To use the Mock Backend:

    kcf_tools --backend mock

## Compatibility

- Release build uses KCF Core v5.6.2
- Core is statically linked into the Tools executable
- Qt6 runtime dependencies come from Ubuntu packages
- The Network Protocol major version remains unchanged
- Rebuild applications when changing the statically linked Core

## Verification

- Real Backend and GUI regression CI
- Virtual LAN test where runner isolation is available
- Native Debian builds for Ubuntu 24.04/26.04,
  AMD64 and ARM64
- Previous physical Wi-Fi validation with UGV02 and OPI5+

## Known limitations

- Gateway restart may require approximately 240 seconds or
  longer for Discovery/session recovery (Core Issue #6).
- Remote Topic resubscription may require manual action.
- Plot history is bounded; CSV export is not a guaranteed
  lossless recorder of every Publisher sample.
- Package build success does not establish full physical
  runtime validation on all four platforms.
